# Project rules

## Git commits
- Never add `Co-Authored-By` or `Claude-Session` lines to commits in this repo.

## Implementation style
- Prefer the simplest implementation that satisfies the request. No speculative abstractions, no unrequested extras.
- No comments unless strictly necessary to explain a non-obvious reason.

## README.md
- Do not edit README.md until the user explicitly says to. It's being rewritten by hand before the project is finalized.
