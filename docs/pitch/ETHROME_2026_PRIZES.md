# ETHRome 2026 — Prizes, Sponsor Bounties & Judging Criteria

Source: https://www.ethrome.org/hackermanual (prizes.html, judging.html)

## Main Prize

**ETHRome Prize**: One year membership at Urbe Hub coworking space in Rome, for up to 3 members of the winning team (selected by judges).

## Judging Criteria

### Minimum requirements to be judged

1. Link to open source code (e.g. public GitHub repo).
2. If deployed on chain: contract address(es) of the deployed demo, testnet or mainnet.
3. Walkthrough video, max 3 minutes.

### Scoring weights (100% total)

| Category                  | Weight | Sub-criteria                                                                                                                |
| ------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------- |
| Creativity                | 10%    | Novelty (0-5) + thematic alignment (0-5)                                                                                    |
| Feasibility               | 15%    | Real-world problem-solving (0-5) + implementation likelihood (0-10)                                                         |
| Innovation & Significance | 25%    | Innovation level (0-10) + impact in relevant space (0-15)                                                                   |
| Code                      | 50%    | Working demo (0-5) + full functionality (0-15) + build difficulty (0-10) + technology leverage (0-10) + usability/UX (0-10) |

Notes:

- Code is half the total score — functional implementation matters most.
- Judges reserve a 7-day post-event window to verify winning repos for irregularities.
- Winners must keep their code open-source for at least 4 weeks after the event closes.

## Sponsor Bounties ($5,000 total)

Sponsors judge and pay their own bounties independently — ETHRome has no say in who wins them. Public repo, README, and a working demo/video are required for all. No limit on how many bounties a team can apply to.

### 1. Arkiv — Web3 Database (EUR 2,500 total)

Source of truth: https://hub.arkiv.network/ethrome (supersedes the ETHRome hacker manual for Arkiv-specific details, e.g. currency is EUR not USD, and no 20:00 Saturday consultation requirement is listed here).

Prize pool is managed and distributed directly by the Arkiv team, separate from ETHRome.

- Mission 01 — Decommission: EUR 500 — "Your app answers, from Arkiv, a question it answers today through a subgraph, Ponder or a Postgres pipeline, and its read path no longer calls the indexer."
- Mission 02 — Built to Expire: EUR 500 — "Something in your app changes because data expired on its own, not because a job deleted it."
- Mission 03 — Live Wire: EUR 500 — Build an app using Arkiv WebSocket subscriptions to react to entity changes, filter events, and update UI from the stream without polling.
- Best Use of Arkiv: EUR 1,000 — strongest qualifying project overall; all qualifying projects compete automatically.

Note: completing all three missions doesn't triple rewards — you enter three prize categories but can only win once.

**Judging criteria** (equal-weight categories):
- 30% — Why Arkiv / Web3 database? (unique capabilities vs. Web2)
- 25% — Technical execution (end-to-end functionality)
- 20% — Usefulness & adoption potential
- 25% — Arkiv feedback (specific examples, reproducible issues)

**Submission requirements**: public GitHub repository, deployed demo, feedback report, and Arkiv evidence via the submission form.

**Arkiv submission form**: https://tally.so/r/vGZ98v — one entry per project/team. Have ready before starting: public GitHub repo link, feedback report, demo, and Arkiv-specific evidence. Also asks for: primary contact name, email, Telegram handle (with @), country; team name (optional for solo builders); team member names, GitHub handles, roles, and countries.

### 2. Swarm — Decentralized Storage ($1,000 total)

- Two winners, $500 each (no fixed categories)

**What they want**: "Build an app where users own their data." Integrate decentralized storage into existing workflows — e.g. AI agent memory, encrypted file sharing, social feeds, media galleries. "There should be a real reason the app needs decentralized storage." Swarm ID (identity layer) strongly recommended but optional. Requires public repo, README, and working demo.

## Submission Rules (general)

- Tick the sponsor box on the ETHRome submission form to qualify for that bounty.
- Public repositories required for all submissions.
- Live demo or video documentation mandatory.
- Sponsors run their own judging independently; ETHRome does not handle sponsor payouts.
- Apply to multiple bounties if genuinely fitting — no application limit.
